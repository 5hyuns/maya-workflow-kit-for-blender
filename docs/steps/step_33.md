# Step 33 — 마킹 메뉴·핫박스가 화면 안에 있게

## 계획 (delegated)

### 문제

- 재점검 3차 (`docs/steps/step_32.md`, `a3_02_rmb_menu.png`): RMB 메뉴의 목록이 재질 항목(step 29)으로 길어졌다. 그래서 화면 가운데
  오브젝트에서 열어도 "Assign Existing Material" 이 뷰 아래(타임라인 밑)로 들어간다.
- step 29 는 **목록 하위 메뉴만** 영역 안으로 밀었다 (`engine.Session._inside_bounds`).
- 핫박스: 커서가 위쪽 가장자리 근처면 메뉴 행이 화면 밖으로 나간다 (step_17.md:67). 행은 늘 가운데 상자 바로 위에 놓이기 때문이다.

### Maya 근거

- research 에는 화면 가장자리 동작이 없다 (hotkeys_and_menus.md §4-§5, interaction.md:26-29 확인). 방사 항목은 커서를 중심으로 하고,
  목록은 링 아래에 둔다 (hotkeys_and_menus.md:252).
- 그래서 가장자리 처리는 이 kit 의 결정이다 (delegated).

### 설계

1. **링 중심은 누른 자리에 고정.** 마킹 메뉴는 누른 점에서의 방향으로 고른다 (flick, 보지 않고 긋기). 중심을 옮기면 누른 점이 이미
   어떤 섹터 안에 들어가 버린다 → 메뉴 전체를 옮기는 방식은 쓰지 않는다.
2. **방사 상자**: 각 상자를 bounds 안으로 민다 (크기 그대로). 고르기는 상자 사각형이 먼저, 그다음 방향이라서
   (`Layout.hit`) 밀린 상자도 같은 섹터에 남는다.
3. **목록 자리** (첫 번째로 들어가는 것):
   1. 링 아래 (지금, Maya 기본).
   2. 링 위.
   3. 링 오른쪽, 그다음 왼쪽. 세로는 중심 높이에 맞추고 bounds 안으로.
   4. 다 안 되면 아래 자리에서 bounds 안으로 밀어 올림.

   1·2 는 가로도 bounds 안으로 민다. 목록만 있는 메뉴(링 없음, 예: 빈 곳 RMB)는 목록을 bounds 안으로 민다.
4. 같은 처리를 루트 메뉴와 제자리 방사 하위 메뉴에 적용한다. 목록 하위 메뉴는 step 29 의 중심 이동을 그대로 쓴다
   (누른 점이 아니라 행 모서리에서 열리므로).
5. **핫박스**: 행 묶음이 위로 넘치면 가운데 상자 아래로 옮긴다 (순서 유지). 아래도 공간이 없으면 넘친 만큼 아래로 민다.
6. bounds = `view.visible_bounds` (사이드바·툴바·투명 헤더 제외, region 좌표). 모달은 이미 Session/HotboxLayout 에 넘긴다.

### 검증

- 헤드리스 (engine 은 bpy 없음):
  - RMB_MESH 를 아래쪽·위쪽·오른쪽 가장자리·모서리에서 열면 모든 행·상자가 bounds 안에 있고, 목록이 방사 상자와 겹치지 않는다.
  - 가운데에서 열면 배치가 그대로다. 빈 곳 RMB 목록, Shift+RMB, W 홀드 메뉴도 확인한다.
  - 핫박스를 위쪽 가장자리에서 열면 모든 행이 안에 있고 가운데 상자와 겹치지 않는다.
  - 기존 `test_step9_engine` 은 그대로 통과해야 한다.
- GUI: 뷰 아래쪽 오브젝트 RMB → 목록 전체가 보임 + 항목 클릭 동작, 핫박스 위쪽 가장자리, 스크린샷.
- 전체 헤드리스·GUI·dogfood.

## 한 것

- `marking/engine.py`:
  - `fit_ring(layout, center, bounds)`: 방사 상자를 bounds 안으로 밀고, 목록은 아래 → 위 → 오른쪽/왼쪽 → 밀어 올리기 순서로 둔다.
    링이 없는 목록 메뉴는 목록을 안으로 민다.
  - `Session` 이 루트 메뉴와 제자리 방사 하위 메뉴에 적용한다. 중심은 누른 점 그대로다.
  - `HotboxLayout._fit_rows`: 위로 넘치는 메뉴 행은 가운데 상자 아래로, 거기도 공간이 없으면 넘친 만큼 아래로.
- `marking/draw.py`: 핫박스 N/S 영역 이름이 가운데 상자나 옮겨진 행과 겹치면 그리지 않는다.
  GUI 스크린샷에서 "Panel Layouts" 가 가운데 상자 위에 겹쳐 그려졌다.
- `tests/test_step29_materials.py`: bounds 없는 세션은 자기 행 위치로 하위 메뉴를 연다. 루트 목록이 이제 움직이므로 고쳤다.
- 테스트: `tests/test_step33_menu_bounds.py` (6), `tests/gui/gui_step33_menu_bounds.py` (7 체크, 스크린샷 3장).

## 남은 것

- 링 중심은 누른 점에 고정이라, 모서리에 아주 가까우면 방사 상자가 서로 붙거나 목록과 가까워질 수 있다
  (헤드리스로 7 개 위치를 확인했고 겹침은 없었다). 손 감각은 manual_checks 에 남겼다.
- 핫박스 W 영역 이름 "Selection Masks" 가 커서가 위쪽에 있을 때 뷰 왼쪽 위 텍스트("User Perspective")와 겹친다. 꾸밈 문제라 그대로 둔다.
