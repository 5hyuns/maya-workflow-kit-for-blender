# 요약 3 — 2차 권장을 반증해 본 결과 (2026-10-26)

자세한 내용: `VERIFY.md` (약점 10장, 지표 민감도, 반증 근거, 판정표, 결정 트리), `INTERVIEW_QUESTIONS.md`. 새 계산: `data/scripts/demand_sensitivity.py`. tavily는 이번 내내 429(차단)로 응답하지 않아 WebSearch/WebFetch로 조사했다.

## 핵심
- **"애니메이션이 중요하다"는 맞다(강). "애니메이션이 1위"는 약하다.** 같은 원자료로 6가지 방식으로 다시 계산하면 애니는 6번 모두 상위 3 안에 있지만, 1위는 2번뿐이다. 그 2번은 Blender 원주민 설문(응답 5,102명 중 Maya 출신 6.4 %)과 일본 채용 공고를 넣은 경우다. 이주자 신호만 쓰면 4가지 모두 **파일 왕복이 1위**다 [사실: 계산].
- 유튜브 "애니메이션" 조회 160만 중 41 %는 "Maya 아티스트가 Blender 해 보기" 반응 영상이고, 33 %는 **"Maya에서 애니메이트하고 Blender에서 렌더"** 하는 영상이다 [사실]. 이 사람들은 애니메이션을 옮기지 않는다.
- 반증 근거: 업계 교육은 반대 방향을 가르친다(Animation Mentor "Maya for Blender Animators"). 애니 공백은 이미 유료 애드온이 메운다(Animation Layers, AniMate Pro, 경쟁품 Maya Config Pro Ani). 실제 사용자 신호는 모델러·TA 쪽이다(외부 이슈 6건 중 애니 0). 만드는 사람도 애니메이터가 아니다 [사실 / 해석은 추정].

## 가장 큰 unknown 3개
1. **키트 관심층 중 Blender에서 실제로 키 애니를 하는 사람의 비율** — I2 전체가 여기에 걸려 있다.
2. **P2의 파일 방향**: Blender→Maya 리그, Maya→Blender 애니(렌더), 게임 엔진 중 어느 것인가. GOALS 1순위(리그 FBX)가 맞는 방향인지가 여기에 달렸다.
3. **애니 감각을 판정할 사람이 있는가**: 본인, 동료, 외부 중 누구인가.

## 확인 계획 (2주, 바뀔 가능성이 큰 것부터)
1. **Day 1 — 사용자 인터뷰 5문항(30분).** 가장 싸고, 결정 규칙과 파일 방향을 바로 바꿀 수 있다.
2. **Day 1–3 — 어느 방향이든 하는 일 먼저**: Y-up 표시, 보고된 손 버그(#80·#84 계열). 경로를 둘로 나누는 문서 작업.
3. **Day 2–5 — 30분 자가 테스트**: Maya 모드에서 Rigify 휴먼 + Rain으로 컨트롤 선택 → CB → S → Graph Editor → IK/FK. 에이전트 dogfood와 본인 녹화 1회. 리그 FBX는 mayapy로 재현만 한다.
4. **Day 2–14 — 바깥 신호**: X 투표 1개(영어), GitHub Discussion 1개(@멘션 없이), 설문 Q-A~Q-D 1주 차 중간 집계, 가능하면 애니메이터 1~3명 녹화.
5. **Day 14 — 결정 트리 적용** (`VERIFY.md` §4). 응답이 100개에 못 미치면 인터뷰 Q5에서 정한 대체 규칙을 쓴다.

1. 회사 밖에서 Blender로 끝낸 마지막 작업과, 그 중간에 Maya로 돌아간 단계 (모델·렌더 / 애니는 Maya / TA 단계 / 아직 없음)
2. Maya에서 키 애니를 업무로 한 기간 (주업 3년 이상 / 가끔 / 거의 안 함)
