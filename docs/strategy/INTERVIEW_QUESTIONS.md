# INTERVIEW_QUESTIONS — 사용자 본인(P1)에게 묻는 5개 (2026-10-26, `/unknowns:interview`)

이유: 사용자 본인이 Maya 경력의 TA/개발자이고, 그 자체로 P1 페르소나다. 아래 답은 설문 100개보다 먼저, 무료로 얻을 수 있는 증거다. 영향 큰 순서. 【권장】은 근거가 가리키는 쪽이지 정답이 아니다 — 사실대로 답하면 된다. 근거는 `VERIFY.md`.

### Q1. 회사 밖에서 Blender로 **실제로 끝낸** 마지막 작업은 무엇이고, 그 중간에 Maya로 돌아간 단계가 있었나요?
- (a) 모델링·룩뎁·렌더(스틸/턴테이블)를 Blender에서 끝냈다 — Maya로 돌아간 단계 없음
- (b) 모델·렌더는 Blender, **애니메이션(또는 리그)은 Maya**에서 하고 가져왔다
- (c) TA 도구(예: VAT 베이크)처럼 **Maya가 꼭 필요한 단계**가 있어서 Maya를 거쳤다
- (d) 아직 Blender로 끝낸 작업이 없다(손 때문에)

**이 답이 바꾸는 것**: 본인이 어느 경로의 P1인지 → "첫 1시간" 기준선을 누구 손으로 잴지. (b)면 VERIFY 2.1의 하이브리드(애니는 Maya) 신호가 본인에게도 맞는 것이고, I3의 파일 방향 = Maya → Blender가 된다. (d)면 ① 손이 여전히 1순위.

### Q2. Maya 경력 중 **키프레임 애니메이션을 업무로** 한 기간은?
- (a) 주업이었다(3년 이상) — Graph Editor 감각을 스스로 판정할 수 있다
- (b) 가끔 했다(테스트·간단한 애니)
- (c) 거의 안 했다(모델링·TA·FX 위주) 【현재 근거상 가장 그럴듯함: GitHub 프로필 "3D generalist", VAT baker】

**이 답이 바꾸는 것**: I2(애니메이터 작업대)의 비용. (a)면 애니 감각 작업의 완료 조건을 본인이 지킬 수 있어 I2 확신도가 오른다. (b)·(c)면 I2의 모든 ⑥ 작업이 외부 애니메이터에게 달리므로, Q4가 "불가"면 I2를 1순위로 두지 않는다.

### Q3. 회사 Maya ↔ 개인 Blender 사이에서 **파일이 실제로 오간** 경험은? (가장 최근 것 하나)
- (a) Blender → Maya: **리그·스킨·애니**가 든 FBX
- (b) Blender → Maya: 메시(모델)만
- (c) Maya → Blender: 애니메이션/캐시(Alembic·USD·FBX)를 가져와 렌더 【이주 영상 조회수로는 가장 큰 흐름】
- (d) 둘 사이에 파일이 오간 적이 없다(완전히 따로 쓴다) / 게임 엔진으로만 보낸다

**이 답이 바꾸는 것**: GOALS의 원래 1순위(리그 FBX, Blender→Maya)가 맞는 방향인지. (a)면 리그 FBX를 1순위로 되돌릴 근거가 생긴다. (c)면 2차 Top 10에 없던 "Maya 애니를 Blender로 가져오기"가 후보로 올라온다. (d)면 ⑧ 전체를 내린다.

### Q4. 2주 안에 **Maya 애니메이터 1~3명**에게 30분(키트로 Rigify/Rain 리그 만져 보기 + 녹화)을 부탁할 수 있나요?
- (a) 3명 가능(동료·지인) 【권장: 결정 1·2를 가장 싸게 확정】
- (b) 1명 가능
- (c) 불가 — 공개 모집(X·Discord·r/animation)에 의존해야 함

**이 답이 바꾸는 것**: 확인 계획의 Step 4를 할 수 있는지. (c)면 애니 감각 항목은 보류하고, 결정 1은 투표·설문만으로 정한다(확신도가 낮은 채로).

### Q5. 2주 뒤 설문 응답이 **100개에 못 미치면** 어떻게 할까요?
- (a) 지금의 잠정 결론(두 집 살림 뼈대 + 측정 후 결정)을 그대로 쓴다
- (b) 기준을 낮춘다: 설문 + 투표 합 50개 이상이고 인터뷰 3명이 같은 방향이면 순서를 바꾼다 【권장】
- (c) 기간을 4주로 늘리고 그때까지 순서를 바꾸지 않는다
- (d) 2차 순서(애니메이션 먼저)를 그대로 쓴다

**이 답이 바꾸는 것**: 결정 규칙의 기본값. 지금 유입(스타 하루 1개)으로는 100응답이 어렵다고 본다 [추정]. 기본값을 정하지 않으면 규칙이 "2차 순서 확정"과 같아진다(VERIFY B10).
