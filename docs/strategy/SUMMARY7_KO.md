## 바뀐 구현 순서 (SUMMARY6 대비)
1. **S 묶음에 L20 을 다시 넣는다** — 다만 "결정 6 의 C 안"으로. 비용은 S 다. 근거: Rigify 63 %.
2. **L19(쿼터니언 표시·키)를 사슬 ⑤에서 꺼내 3번(L11) 바로 앞으로 당긴다.** 받은 리그와 FBX 로 가져온 리그 대부분에서 S 가 회전을 키하지 않는 것은 사실상 BLOCKED 다. 비용은 M 이고 L11 의 커브 재계산과 같은 compat 오일러 코드를 쓴다.
3. **L11 은 「계획」을 쓸 때 실험 결과를 넣고 범위를 좁힌다.**
   - 이번 프로토타입(`kyu7/e2_post.py`, `m2.py`)을 테스트의 씨앗으로 쓴다.
   - 남은 일: rest 를 `bone.matrix_local` 에서 계산(현재 프레임 값 쓰면 틀림, 실측), 아마추어 Null 노드 제거(미실험), deform-only, Unity / Unreal 실기 확인.
   - 비용 L → M+ 로 본다.
4. **L12 에 "가져온 본 = XYZ + 오일러 키"(결정 4 D)를 더한다.** Blender 임포터가 PreRotation 파일을 약간 어긋나게 읽는 현상(0.27 cm, [U])도 L12 에서 확인한다.
5. A4(여러 skinCluster)는 M 에서 S 로 줄인다(질문 + 읽기 전용 목록 + 경고). A3(숫자 표시)은 결정 7 설계로 진행한다.
6. 사슬 ①(L1)에 "Custom Shape 와이어 히트 판정"과 "내보내기에서 모양 커브 제외"를 넣는다.
