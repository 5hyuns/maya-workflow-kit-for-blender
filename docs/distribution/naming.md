# Naming — Maya Workflow Kit

## Current (user decision 2026-10-20, step 125 — `docs/user_decisions.md` 12 revision)

- **Name: Maya Workflow Kit** (store / display name, no "Blender" — ToS 2.1). **Repository: Maya Workflow Kit for
  Blender**, slug `maya-workflow-kit-for-blender` (https://github.com/5hyuns/maya-workflow-kit-for-blender). The user's
  reason: "Allset" has no brand power — the name alone did not say what it is or who it is for.
- Unchanged: id `allset` (kept neutral so a name change requested by Autodesk touches only the display name), package,
  prefixes, tagline "The whole Maya workflow in Blender, in one install".
- Trademark risk accepted by the user: Autodesk's guidelines prefer the "for Maya" form with the own name first; this
  name leads with Maya. Fallback if the store review objects: **Workflow Kit for Maya Users**. The name is always
  followed by "for Maya users, in Blender" and the non-affiliation notice stays in every material.

The sections below are the step 111 naming run ("Allset for Maya Users"), kept as history.

## Step 111 run — Allset for Maya Users

Source: copy-masters run 2026-10-19 "name-and-tagline" (`hermes/copyruns/copy-runs/blender-maya-kit/2026-10-19-name-and-tagline/10-final.md`,
summarised here; the run itself stays outside the repository). Brief: a free Blender extension that brings the
complete Maya workflow to Blender (hotbox, marking menus, Channel Box, Attribute Editor, Maya layout, menu sets,
shelves, option windows, Maya concepts), listed on extensions.blender.org.

### Final (step 111)

- **Name: Allset for Maya Users** — id `allset` (no "maya" in id, URL or package; Autodesk trademark guidelines allow
  "for / for use with" references with our own name first, `docs/distribution/extensions_audit.md`).
- **Tagline: The whole Maya workflow in Blender, in one install** (50 characters, no end punctuation, platform limit 64).
- Why "Allset": "all set" — other add-ons give one piece each (a pivot, a keymap, a shelf, a theme); Allset brings the whole
  Maya workflow at once. "for Maya Users" tells a reader who searched "maya" on the store who it is for.
- Platform search (2026-10-19): no extension with the same name. An unrelated food-pickup app is called Allset (different field).

### Message used in README / preferences / splash (step 111)

Other tools give you one piece at a time — a pivot, a keymap, a shelf, a theme. Allset brings the whole Maya workflow
into Blender in one install: hotbox and marking menus, Channel Box, Attribute Editor, Outliner, menu sets, shelves, option
windows, Freeze / History concepts, centimetre units and pCube1-style naming.
