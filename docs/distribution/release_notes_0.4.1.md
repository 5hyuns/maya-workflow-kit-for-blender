**0.4.1 — surfaces, layers, light linking and more primitives** (Blender 4.5 LTS – 5.2)

Added
- Pipe, Helix, Gear, Soccer Ball, Super Ellipse, Spherical Harmonics and Ultra Shape primitives, shaped like Maya's.
- Surfaces menu: Loft, Revolve, Extrude, Birail, Boundary, Square, Attach, Detach, Insert Isoparms, Rebuild and more.
- Animation Layers with the Layer Editor's Anim tab, and Character Sets.
- Light and shadow linking with a Light Linking Editor.
- More UV Editor commands (Map / Straighten Border, Match Grid, Layout Along, Stack Similar, Distribute) and selections.
- Mesh Display: vertex normals (set, lock, average), Apply Color, colour set editing, Prelight.
- Construction History on / off in the Status Line.
- Repeat Last (G) also repeats menu, shelf and marking-menu commands.

Changed
- Component mode keeps your Move / Rotate / Scale tool.
- Maya-style Time Slider ruler, selected-face and edge look, manipulator planes.
- The right-click marking menu list stays under the ring.
- Undo and Redo say what they undid.

Fixed
- Clicking an option box (❒) in a menu opens its options window.
- Alt+right-drag zooms the UV / Image Editor again.
- Quick marking-menu flicks near the bottom of the window pick the right item.

Thanks to everyone who reported problems from real work.
