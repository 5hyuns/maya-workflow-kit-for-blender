# Surface brief — site/index.html (product landing, Persuade)

Scope: one-page landing for Maya Workflow Kit, English. Audience: Maya artists deciding in seconds whether this is a real Maya
workflow or a keymap skin. Action: download the zip (GitHub Releases; store link later). Proof: the real UI moving (feature
clips), facts per workflow, the one-click way back. Constraints: facts only, no comparisons, trademark notice in the footer,
media credits with the media, page weight managed (videos lazy, posters first).

## Direction contract

THESIS: The page is a Maya shelf. Six workflow tabs sit in a shelf strip the way Maya's shelf tabs do; picking one plays that
workflow in a viewport and lists its facts in a Channel Box column. Refuses the category default of a hero headline over a
grid of feature cards with icons.

OWN-WORLD: Maya 2022 greys (#1e1e1e canvas, #2b2b2b base, #373737 panels, #444 rules, #5c5c5c viewport with Maya's gradient
#889db3 → #0d0d0d), Maya logo teal #00bcbb as the only accent (active tab bar, channel names, links), Autodesk Hello Yellow
#ffff00 only for the press moment (download button, active key chip), black ink on accents. Inter. Square-ish 4–6 px corners,
1 px #444 rules, dense UI-sized labels next to large lockup type; the "::::" tear-off handle and dotted rules as chrome.

STORY: The visitor recognises Maya's shelf and Channel Box before reading a word, sees each workflow working in Blender,
learns nothing changes until they choose Maya and one click goes back, then downloads.

FIRST VIEWPORT: Top: a menu-bar nav (product name left, sections, GitHub right). Left column ~38 %: lockup "Maya Workflow Kit"
/ "for Maya users, in Blender", tagline, one sentence, yellow primary "Download the zip" + secondary "Watch the tour". Right
~62 %: the viewport frame playing the hotbox clip, with the shelf strip of six tabs directly above it and the Channel Box
column of facts at its right edge. Shelf + viewport + facts are visible without scrolling at 1440 × 900.

FORM: Shelf-tab index (structure 5 of 7 on the ordered list), seed key 4d21a296. Signature interaction: shelf tab switch
(click, arrow keys, 1–6) swaps clip, poster and Channel Box facts in place; the Maya | Blender switch section flips one
screenshot between plain Blender and Maya mode.
